Quick Fix - Automobile Service Management System

ระบบบริหารจัดการคิวและบริการอู่ซ่อมรถยนต์ (Node.js, Express, MySQL)

Live Demo: https://quickfix-7fky.onrender.com

-------------

Demo Accounts for Testing (บัญชีทดสอบระบบ)

ผู้ตรวจสามารถนำบัญชีด้านล่างนี้ไปทดลองเข้าใช้งานตามแต่ละสิทธิ์ (Role) ได้ทันที:
_____________________________________________________________________________________________________
| บทบาท   | (Role)      | Username / Email  | Password      | ขอบเขตการทำงาน                       |
| :---     | :---        | :---              | :---          |                                      |
| User     | ลูกค้า        |                   |               | จองคิว, เช็กสถานะผ่านหน้าเว็บ             |
| Staff    | ช่าง/พนักงาน  | staff01           | 123456        | อัปเดตสถานะงาน, บันทึกการซ่อม           |
| Admin    | ผู้ดูแล        | admin01           | 123456        | ดู Dashboard, จัดการคิว, คิดเงิน/ชำระเงิน   |

---

### 🚀 Key Features
* ระบบจองคิวออนไลน์สำหรับลูกค้า
* Real-time status tracking
* Dashboard สรุปยอดรายได้/ค่าใช้จ่ายสำหรับ Admin
* ระบบจัดการสถานะการซ่อมสำหรับ Staff
